## Overview

Dual Wield adds two-weapon combat to RimWorld, allowing colonists and raiders to carry and use a primary weapon and an off-hand weapon simultaneously. Configurable accuracy penalties balance the off-hand weapon, and the mod applies dual-wield behavior to enemy raiders for more varied combat encounters.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Dual Wield** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Two-Weapon Carry** | Colonists equip and carry both a primary and an off-hand weapon |
| **Accuracy Penalties** | Per-weapon-class configurable miss-chance for off-hand weapon use |
| **Enemy Support** | Raiders spawn with dual-wield loadouts for more challenging encounters |
| **Mod Weapons** | Automatically extends dual-wield to weapons added by other RimWorld mods |
